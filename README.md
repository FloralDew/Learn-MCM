# Learn MCM
9/14/2025 FloralDew

MCM, Mathematical Contest in Modeling, is a prestigious contest among worldwide university students. This repo contains several prevailing algorithms you can use in mathematical modeling. The accompanying video material is available here https://www.bilibili.com/video/BV1EK41187QF/.

All pdf files are directly forwarded from @江北, bilibili @数模加油站. I refine some codes (for example, simplify loops through matrix calculations offered by numpy, and thus make the code fit numpy style better) and post them on github.
